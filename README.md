# 非遗文化交流平台 · 线上作品集

一个纯静态的非遗主题网站，包含**两个页面**：主站介绍页，以及可点进交互的「非遗中国」卫星地图子页面。

**在线访问**：https://hank1234-c.github.io/feiyi-china-site/

## 页面结构

```
feiyi-china-site/
├─ index.html             主界面：非遗文化交流平台（平台概览 / 资源中枢 / 成果转化 / 互动体验 / 技术架构 / 公益传播 / 服务对象）
├─ 非遗中国.html           子页面：国家级非遗代表性项目卫星交互地图（1557 项代表性项目 · 3610 子项 · 33 省级行政区 · 10 大门类）
├─ assets/
│  ├─ css/style.css       主界面样式（宣纸 · 朱砂 · 墨线国风视觉，含响应式与打印样式）
│  └─ js/main.js          主界面交互（检索、弹窗、标签页、预约、数字滚动等）
├─ .gitignore
└─ README.md
```

## 两页如何互通

- **主页 → 子页面**：页头右上角「非遗卫星地图 →」按钮（朱砂红主按钮），首屏 hero 区域另有一个同款入口按钮，页脚「体验」栏也有文字入口
- **子页面 → 主页**：地图页右上角（手机端为右下角）「‹ 返回平台首页 / 返回」按钮，深色玻璃拟态风格，与地图 UI 统一
- 链接地址保持干净：`/` → 主界面，`/非遗中国.html` → 地图子页面（中文文件名由服务器自动 URL 编码，已验证可正常访问）

## 技术说明

- **纯静态零依赖**：不使用任何框架、CDN 或外部图片字体，克隆下来直接开浏览器就能跑
- 主界面依赖 `assets/` 下的 CSS/JS 两个文件；子页面为完全自包含的单文件（Leaflet 1.9.4 已内联，11 张配图为 base64 data URI）
- 子页面地图底图使用 Esri World Imagery 卫星瓦片（需联网加载）
- 响应式适配桌面与手机，已验证 1440px / 390px 两种视口

## 本地预览

```bash
# 方式一：直接双击 index.html
# 方式二：起一个静态服务器（推荐，避免部分浏览器 file:// 限制）
npx serve .
# 或
python -m http.server 8000
```
